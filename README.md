# StreamVerse Android TV source

This repository contains the StreamVerse patch and build workflow.

StreamVerse is a GPLv3 modification of [NuvioTV](https://github.com/NuvioMedia/NuvioTV). The GitHub Actions workflow fetches the upstream source, applies `streamverse.patch`, and produces an installable universal Fire TV debug APK.

No private add-on URLs, provider credentials, or debrid keys are committed to this repository.
